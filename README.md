# LiteracyPlatform

Веб-платформа для детей **3–6 лет** (детские сады, семьи): ребёнок слушает вопрос, нажимает на картинки и учится как в игре — читать уметь не нужно. Интерфейс и уроки на **русском, казахском и английском**, есть светлая и тёмная тема.

> **Статус: рабочий прототип.** Публично не запускался, реальных пользователей и дохода нет. Ниже — что уже есть и чего нет (раздел «Ограничения»).

*English:* a web platform for kids aged 3–6 (kindergartens and families). Children hear the question, tap pictures and learn through play — no reading needed. RU / KK / EN interface and lessons, light and dark themes. Working prototype: no public launch, no users, no revenue yet. React + Node/Express + PostgreSQL (Prisma).

## Что умеет

- **Родитель/воспитатель:** регистрация, профили детей, прогресс (XP, уровни, серия дней, значки, графики), уведомления, таблица лидеров.
- **Ребёнок:** карта из 25 уроков, озвучка вопросов, ответы-картинки, повтор после ошибки без штрафов, звёзды и XP.
- **Типы заданий:** выбери картинку, найди лишнее, найди букву, сосчитай, соедини пары (+ старые текстовые типы).
- **Языки:** RU / KK / EN. Один урок хранит переводы внутри себя; уроки про буквы собраны отдельно для каждого алфавита.
- **Админка:** пользователи, статистика, создание и редактирование уроков (в т.ч. заданий для малышей и переводов).

## Быстрый старт (локально)

Нужны Node.js 20+ и Docker (для PostgreSQL).

```bash
# 1. база данных
docker compose up -d

# 2. сервер
cd server
cp .env.example .env          # впишите JWT_SECRET (openssl rand -hex 32)
npm install
npm run db:setup              # миграции + программа уроков + демо-данные
npm run dev                   # http://localhost:5000  (проверка: /health)

# 3. клиент (в другом терминале)
cd client
npm install
npm run dev                   # http://localhost:5173
```

## Переменные окружения (сервер)

См. `server/.env.example`. Главное: `DATABASE_URL`, `JWT_SECRET` (обязательно свой), `CLIENT_URL`, `ADMIN_PASSWORD` (в production seed без него не запустится), `STREAK_UTC_OFFSET`.

## Как добавить или изменить уроки

- **Через админку:** «Уроки» → «Новый урок» / «Редактировать». Вкладка «Переводы» принимает JSON `{ "kk": {...}, "en": {...} }`.
- **Через код:** программа генерируется в `server/prisma/curriculum.js` (слова на трёх языках, шаблоны вопросов, список уроков). Правьте и запускайте `npm run prisma:seed` — уроки `k-01…k-25` обновятся (правки из админки в них будут перезаписаны).
- Формат заданий описан в комментарии в начале `curriculum.js`.

## Ограничения (честно)

- **Нет роли воспитателя и групп** — сейчас каждый ребёнок привязан к родителю. Для детских садов это главное, что стоит доделать.
- **Баллы считает браузер**, правильные ответы приходят вместе с уроком — результат можно подделать. Для детей 3–6 лет некритично, но для рейтингов стоит перенести проверку на сервер.
- **Озвучка** использует голоса браузера; на многих устройствах нет казахского голоса (кнопка 🔊 скрывается). Для надёжности нужны записанные аудиофайлы (поле `audio` в задании уже поддерживается).
- **Картинки — эмодзи**, на разных устройствах выглядят по-разному.
- **Тексты уведомлений родителям** формируются на сервере только на русском.
- **Нет автотестов** и CI.
- **CORS открыт для всех источников** (авторизация по Bearer-токену, не cookie) — при желании ограничьте в `server/src/app.js`.
- Данные детей (имя, возраст) — персональные данные; перед запуском проверьте требования законодательства вашей страны к их хранению.

## Безопасность перед запуском

1. Задайте **свой** `JWT_SECRET` и `ADMIN_PASSWORD`; не используйте демо-пароли.
2. Не коммитьте `.env` (он в `.gitignore`).
3. Не запускайте seed с демо-данными на боевой базе (`SEED_DEMO=false`).
