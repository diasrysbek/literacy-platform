# Клиент (React + Vite)

Подробная инструкция по запуску всего проекта — в [README.md](../README.md) в корне.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Переменная `VITE_API_URL` задаёт адрес сервера (по умолчанию в разработке — `http://localhost:5000`).
